## 1. What changed from v8 (non-outcome information only)

1. **Benchmark does not gate admission or testability; pinned XNYS session calendar.**

The session calendar is the pinned XNYS session manifest `docs/reference/calendar-manifests/vs1-xnys-2007-11-01-2026-06-30.json` (schema `grid.xnys-session-manifest.v1`, build `exchange_calendars:4.11.2:pandas:2.3.3:numpy:2.4.6:tzdata:2026.6:XNYS:2007-11-01:2026-06-30`, exact bytes SHA-256 `9b8f0079f89eb6b5f744a6466373fb9af1af74abaafb01b68dc89e39984372ac`), replacing "XLK's admitted closes" (v6 §3). 2. **Labels without XLK subtraction; rank IC invariance.**
   Each issuer's label is its split-first forward close-to-close return over horizon `h` sessions with no XLK subtraction. Because subtracting a single finite benchmark return from every issuer on date `t` is order-preserving (up to floating-point rounding), the per-date cross-sectional Spearman rank IC equals v8's XLK-relative rank IC on every date where XLK's return is finite (precedent: v6 §9 "The rank IC does not depend on it; XLK enters only the reported magnitudes"; sectors-v4 §3 "The rank IC is unchanged by the benchmark; only the reported magnitudes differ"). The momentum baseline and SIC-group-neutral IC are likewise rank- or demean-invariant to a common finite benchmark return.
3. **XLK-relative magnitudes (reported only, never gating).**
   XLK-relative magnitude fields (`buyer_minus_benchmark`, `nonbuyer_minus_benchmark`, `large_line_buyer_minus_benchmark`, `small_line_buyer_minus_benchmark`) are reported for a window only if `XLK` passes the unchanged v8 admission rule for that window. Otherwise those fields read `"not available: benchmark not admitted"`, and `XLK` is not read for that window. Magnitudes never gate admission, Stage-0, selection, calibration, holdout, or verdict. On the bound discovery probe (`benchmark_admitted = false`), all discovery XLK-relative magnitude fields read `"not available: benchmark not admitted"`.

   `XLK` remains not admitted on the discovery probe; there is no discovery probe rerun; no admission or cross-check tolerance changes anywhere; and no power claim is made prior to sealing post-admission Stage-0 on the 195-issuer panel.
