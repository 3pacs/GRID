# V5 Phase 4 + Phase 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the V5 transformation — add intelligence search, canvas evidence/LLM/embedded viz, timeline causal arrows, graph analytics, canvas→prediction pipeline, geo-spatial flows, MinIO blob store, Redpanda event stream, Prefect workflows, frontend TypeScript migration, and CI/CD.

**Architecture:** Phase 4 adds the "investigation" layer — search corpus, pin evidence, LLM-explain connections, embed charts in canvas, and convert visual theses to scored predictions. Phase 5 adds operational maturity — geo-spatial flow visualization, durable infrastructure (MinIO, Redpanda, Prefect), TypeScript frontend, and CI/CD automation.

**Tech Stack:** PostgreSQL FTS (tsvector/GIN), React Flow custom nodes, D3 embedded viz, deck.gl, NetworkX, MinIO, Redpanda, Prefect, TypeScript, GitHub Actions.
